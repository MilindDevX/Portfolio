## Project Overview

QuickNotes is designed for speed and focus. It provides a distraction-free, minimalist dark-mode environment for capturing ideas in Markdown with **< 50ms live render latency**, complete with folder-based organization and local-first persistence.

## The Problem

Note-taking apps are almost universally over-featured — heavy Electron apps, cloud-sync dependencies, or complex block editors that get in the way of thought. QuickNotes is built around one principle: type in Markdown, see the result instantly, organize simply.

## Technical Architecture

The application focuses on frontend performance and user experience, built with **React** and **Tailwind CSS**, connected to a lightweight **Express.js** backend for optional note sync.

- **Live Markdown Rendering**: Used `react-markdown` with `remark-gfm` for GitHub Flavored Markdown support. Rendering is debounced at 50ms — fast enough to feel instantaneous, efficient enough to avoid re-renders on every keystroke.
- **Local-First Architecture**: Notes are written to `localStorage` first, with the Express.js backend acting as an optional sync layer. This ensures the app functions completely offline with zero data loss risk.
- **Glassmorphism UI**: Built a custom design system in Tailwind CSS with frosted-glass card effects, a monospace editor pane, and a clean two-panel split layout — editor left, preview right.
- **Folder Organization**: Implemented a recursive folder tree component with drag-and-drop reordering (using native HTML5 drag events) and persistent collapsed/expanded state.
- **Performance**: Initial bundle size under 180KB gzipped. First Contentful Paint < 800ms on a cold load.

## Key Outcomes

- **< 50ms** live Markdown-to-HTML render latency delivering a seamless, real-time writing experience.
- Local-first data model ensures **zero data loss** even in offline or incognito sessions.
- Sub-180KB initial bundle achieving **< 800ms FCP** on a cold load without code splitting.
- Glassmorphism dark-mode interface that has been cited as the visual reference for two subsequent projects.
